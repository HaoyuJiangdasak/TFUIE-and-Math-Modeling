## 1. 背景速览：五条硬结论（为什么文档长这样）

以下结论来自对论文 PDF 逐页精读 + 对冻结提交代码的逐行核对，是本方案的地基：

1. **增强推理只依赖两个网络**：水下内容编码器 `E_A` + 增强生成器 `G_B`。官方仓库自带这两个训练好的权重（`checkpoints/latest_net_E_A.pth`、`latest_net_G_B.pth`），所以"不训练、只推理"在官方资产层面是成立的。
2. **README 的测试命令不能直接用**：`--model cycle_gan` 会实例化完整训练类（需要陆地图、mask、VGG19 等一堆训练依赖）。作者写了真正的单向增强类但没注册进模型发现机制——本文档的代码改动①解决了它。
3. **论文没有报告 PSNR/SSIM，也没有报训练时长和测试划分细节**：复现协议里凡是论文没写死的（数据划分切法、epoch 数、学习率日程），都由本文档显式选定并记录，这是"协议差异"而非"复现失败"。
4. **下游评价的现成资产是 bubbliiiing 风格 U-Net 仓库**（`unet_test/`）：默认值已对准 SUIM（8 类、vgg 主干、256×256、固定种子、cudnn 确定性），但有四个坑（bmp 硬编码、GPU 号硬编码、model_path 死路径、numpy 版本敏感），全部已在 §3.2 改掉或写进流程。
5. **公开代码原样训练 = 论文消融 Model C**（SACM 完全失效：`loss_con` 没加进总损失、`netPFC` 不在优化器里）——推理级方案不受影响（用的官方权重），但**如果**将来升级训练（附录 A），必须先修这六处，否则烧钱跑出来的是错误结果。

## 5. 验收标准

- **硬标准（达成 = 复现成功）**：TFUIE 版 mIoU > Raw 版 mIoU，且方向稳定（不看单张图，只看 110 张集合指标）。
- **软标准**：差值在 +1 ~ +4 个百分点区间（论文 +2.6；划分/实现差异会导致浮动）。
- **失败即排查**：方向为负 → 按 §7 顺序排查；全部排掉后如实写进记录（官方权重 + 自定划分与作者内部协议存在预期内偏差），这是诚实汇报的一部分，不是失败。
- **汇报可直接用的两句话**：①复现了"任务友好增强提升下游分割"这一核心主张；②在 SUIM 官方 110 张测试集上，TFUIE 增强训练的 U-Net 比原图训练高 X 个百分点（论文口径 +2.6）。

| 6 | test.py 输出全黑 / 与输入相同 | 权重没被加载 | 确认 `checkpoints/tfuie_official/` 下两个 pth 文件名原样（`latest_net_E_A.pth`、`latest_net_G_B.pth`）；看控制台 loading network 提示 |

## 10. 附录 A：进阶路线（核心复现，本档未执行）

如要升级为"自己训练增强模型"（成本约 +¥60–200、+1–2.5 天，3090）：

1. **必须先修六处**（当前仓库未改，详见《TFUIE逐页讲解与复现准备.md》§4–§5）：
   - `loss_G` 加入 `loss_con`，且 `netPFC.parameters()` 进 `optimizer_G`（否则 SACM 失效 = 复现出 Model C）
   - `--gan_mode vanilla`（论文 Eq.7 是 −log 形式，代码默认 lsgan）
   - 删 `models/cycle_gan_model.py` 中 `lambda_P = self.opt.lambda_P` 死读取（首步即崩）
   - `--n_epochs 100 --n_epochs_decay 100 --gpu_ids 0`
   - 训练入口用 `cycle_gan_model.py`（训练类），数据按 `trainA/trainB/trainC` 三目录准备
2. **数据**：在推理级基础上加 Flickr2K（抽 1,634 张、裁 512→缩 256，渠道见《复现下载清单.md》）
3. **训练命令**（修完六处后）：
   ```bash
   python train.py --dataroot ./datasets/TFUIE --name tfuie_repro --model cycle_gan \
     --gpu_ids 0 --batch_size 1 --n_epochs 100 --n_epochs_decay 100 \
     --lr 0.0002 --lr_policy linear --gan_mode vanilla --display_id -1
   ```
4. **训练换自己的权重后**：§4.6 的 `checkpoints/tfuie_official` 换成自训的 `latest_net_E_A/G_B`，其余流程原样重跑一遍即得完整对比（官方权重版 vs 自训版 vs Raw，三行表）。
