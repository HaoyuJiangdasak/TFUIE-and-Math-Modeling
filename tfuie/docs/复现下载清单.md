## 二、需要你手动下载的（按优先级排序）

### 1. SUIM 数据集（必须，最先下）｜约 3–5 GB
**用途**：增强训练的水下域 `trainA` + 语义指导标签 `trainC` + 下游分割任务的训练/测试。

渠道（三选一，按国内速度排序）：
1. **OpenDataLab**（推荐）：opendatalab.com 搜 `SUIM`，注册后网页下载或用其 CLI 工具
2. **Kaggle**：kaggle.com 搜 `SUIM` / `semantic segmentation of underwater imagery`，选带 images+masks 完整版的镜像
3. **官方**（需科学上网）：irvlab.cs.umn.edu/resources/suim-dataset，或 GitHub `irvlab/SUIM`（内含 Google Drive 链接）

下载后检查：图像与 mask 成对、数量一致（官方全集 1,635 张；论文口径 1,634，差异已记录，等作者文件清单核实）。

### 2. Flickr2K（必须）｜完整包约 11–13 GB，只需其中 1,634 张
**用途**：增强训练的陆地域 `trainB`（随机 1,634 张，裁 512→缩 256）。

渠道：
1. **OpenDataLab / Kaggle** 搜 `Flickr2K`（有现成镜像，不用科学上网）
2. **官方**：BasicSR 仓库（github.com/xinntao/BasicSR）的数据集文档里给的是 Google Drive 链接

建议：全包下载到本地后**先别删**，抽好 1,634 张并保存清单后，本地留一份完整包备份。

### 3. ChinaMM / URPC 检测数据（下游评价，可后置）｜约 1–2 GB
**用途**：目标检测任务（0B 海参 / 1B 海胆 / 2B 扇贝），论文口径 2,071 train / 676 test。

渠道：
1. **FERNet 官方渠道**：ECVA 官网（ecva.net）ECCV 2020 论文页搜 `Dual Refinement Underwater Object Detection`（paper 3425）→ 代码链接；GitHub 搜 `FERNet underwater`
2. **国内流传版**：CSDN / 百度网盘搜 `URPC 数据集` 或 `ChinaMM 水下机器人`（比赛公开数据，多个检测论文都用）
3. 都对不上 2,071/676 划分时 → 记录差异，列入给作者的提问清单

注意：URPC 常见版本含第四类海星（starfish），本文只用三类，整理时按论文三类筛选。

### 4. UFO-120（下游显著性评价，可后置）｜约 1–2 GB
**用途**：显著性检测（1,500 train / 120 test + saliency mask）。

渠道：官方 irvlab.cs.umn.edu/resources/ufo-120（Google Drive）；Kaggle 搜 `UFO-120`。

### 5. USOD10K（下游显著性评价，可后置）｜约 5–10 GB
**用途**：显著性检测（共 10,255 张，70 类显著目标 / 12 类场景）。

渠道：GitHub 搜 `USOD10K`（TIP 2023 原论文作者发布页）；OpenDataLab / Kaggle 亦可能有镜像。

### 6.（备用）VGG 权重手动下载方法
仅当上面 `model_data/` 里的文件损坏时才需要。浏览器直接打开下载即可，或用支持断点续传的工具：
```
https://download.pytorch.org/models/vgg16-397923af.pth   （528 MB）
https://download.pytorch.org/models/vgg19-dcbb9e9d.pth   （548 MB）
```

PowerShell 命令行版（支持断点续传）：`curl.exe -L -C - -o vgg16-397923af.pth https://download.pytorch.org/models/vgg16-397923af.pth`

## 四、下载完成后传到 AutoDL 的方法（租卡后再做）

1. **scp（推荐）**：Git Bash 直接用。实例详情页会给完整命令，形如：
   ```
   scp -r -P <端口> ./datasets root@<实例地址>:/root/autodl-tmp/
   ```
2. **AutoDL 网盘中转**：控制台绑定阿里云盘 → 网页上传到网盘 → 实例内复制（大文件更稳、可断点）
3. **JupyterLab 网页上传**：适合 2 GB 以内的小文件
4. 传数据时用**无卡模式开机**（约 0.1 元/时），别开着 GPU 干等
5. 实例内补依赖用学术加速：`source /etc/network_turbo`
