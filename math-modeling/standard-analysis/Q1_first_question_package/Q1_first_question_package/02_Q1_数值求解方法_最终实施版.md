# 2. PDE 类型与数值特征

## 2.1 温度方程

\[
\rho c_p\frac{\partial T}{\partial t}
=
\frac{1}{r}\frac{\partial}{\partial r}
\left(
rk\frac{\partial T}{\partial r}
\right).
\]

问题 1 中：

- \(\rho,c_p,k\) 为常数；
- 方程为线性；
- 属于抛物型扩散 PDE；
- 空间离散后形成刚性扩散型 ODE 系统。

## 2.2 水分方程

\[
\frac{\partial C}{\partial t}
=
\frac{1}{r}\frac{\partial}{\partial r}
\left[
rD(C)\frac{\partial C}{\partial r}
\right],
\]

其中

\[
D(C)=7\times10^{-9}\exp(-0.89/C).
\]

特点：

- 非线性；
- 变系数；
- 必须保持守恒通量形式；
- 不能把 \(D(C)\) 固定为初始值；
- 不能错误写成
  \[
  D(C)\left(C_{rr}+\frac1rC_r\right)
  \]
  而忽略变系数对通量的影响。

## 2.3 温度与水分耦合

问题 1 当前给定参数下，温度方程和水分方程互不依赖：

\[
\boxed{T\text{ 与 }C\text{ 可分别求解。}}
\]

这意味着 Q1 不需要构造一个大规模耦合 Newton 系统。

# 4. 空间离散：圆柱 cell-centered 有限体积

采用 \(N\) 个径向控制体。

## 4.1 控制体面

\[
r_j^f=j\Delta r,
\qquad
j=0,1,\ldots,N,
\]

其中

\[
\Delta r=\frac{R}{N}.
\]

## 4.2 单元中心

\[
r_i=\left(i+\frac12\right)\Delta r,
\qquad
i=0,1,\ldots,N-1.
\]

因此：

- 第一控制体：\(0<r<\Delta r\)；
- 最后控制体：\(R-\Delta r<r<R\)。

## 4.3 圆柱几何量

面面积：

\[
A_j=2\pi Lr_j^f.
\]

控制体体积：

\[
V_i=
\pi L\left[
(r_{i+1}^f)^2-(r_i^f)^2
\right].
\]

实际代码可以约去所有方程中的共同因子 \(\pi L\)，但概念上应始终保持“面积 × 通量 / 体积”的守恒结构。

---

# 5. 温度方程的有限体积离散

定义径向向外热通量：

\[
q=-kT_r.
\]

内部面 \(j=i+1\) 的离散通量：

\[
q_{i+1/2}
=
-k\frac{T_{i+1}-T_i}{\Delta r}.
\]

对第 \(i\) 个控制体做能量守恒：

\[
\rho c_p V_i\frac{dT_i}{dt}
=
A_iq_i-A_{i+1}q_{i+1}.
\]

因此：

\[
\boxed{
\frac{dT_i}{dt}
=
\frac{
A_iq_i-A_{i+1}q_{i+1}
}{
\rho c_pV_i
}.
}
\]

内部通量会在全域求和时两两抵消，因此便于做整体能量守恒验证。

---

# 6. 水分方程的有限体积离散

定义径向向外水分扩散通量：

\[
J=-D(C)C_r.
\]

内部单元扩散系数：

\[
D_i=D(C_i).
\]

内部面扩散系数建议采用调和平均：

\[
D_{i+1/2}
=
\frac{2D_iD_{i+1}}{D_i+D_{i+1}}.
\]

于是：

\[
J_{i+1/2}
=
-D_{i+1/2}
\frac{C_{i+1}-C_i}{\Delta r}.
\]

控制体守恒式：

\[
V_i\frac{dC_i}{dt}
=
A_iJ_i-A_{i+1}J_{i+1}.
\]

即：

\[
\boxed{
\frac{dC_i}{dt}
=
\frac{
A_iJ_i-A_{i+1}J_{i+1}
}{
V_i
}.
}
\]

这一步必须保留通量形式，不能将非线性扩散率简单提到空间微分算子外。

---

# 7. 中心 \(r=0\) 的处理

有限体积法下不直接出现

\[
\frac1r
\]

的数值代入。

在中心面：

\[
r_0^f=0,
\]

因此圆柱面积

\[
A_0=2\pi Lr_0^f=0.
\]

同时轴对称条件给出：

\[
T_r(0,t)=0,\qquad C_r(0,t)=0.
\]

因此中心面净通量天然为 0。

第一控制体只需要右侧面通量：

\[
\rho c_pV_0\dot T_0=-A_1q_1,
\]

\[
V_0\dot C_0=-A_1J_1.
\]

所以：

\[
\boxed{\text{程序中不需要、也不允许在 }r=0\text{ 直接计算 }1/r.}
\]

---

# 8. 中心值重构

cell-centered FVM 的第一个未知量位于

\[
r=\frac{\Delta r}{2},
\]

而题目需要输出真正的

\[
r=0.
\]

根据轴对称偶函数展开：

\[
u(r)=u(0)+ar^2+O(r^4),
\]

利用前两个单元中心可得：

\[
\boxed{
u(0)\approx\frac{9u_0-u_1}{8}.
}
\]

对温度和水分均可采用：

\[
T(0)\approx\frac{9T_0-T_1}{8},
\]

\[
C(0)\approx\frac{9C_0-C_1}{8}.
\]

---

# 9. 表面温度 Robin 边界

题设：

\[
-kT_r(R,t)
=
h[T_s-T_\infty(t)].
\]

其中

\[
T_s=T(R,t).
\]

为了保证表面处理不降低整体空间精度，采用基于最后两个单元中心和表面值的二阶导数重构：

\[
T_r(R)
\approx
\frac{
8T_s-9T_{N-1}+T_{N-2}
}{
3\Delta r
}.
\]

代入 Robin 条件：

\[
-k
\frac{
8T_s-9T_{N-1}+T_{N-2}
}{
3\Delta r
}
=
h(T_s-T_\infty).
\]

解得：

\[
\boxed{
T_s=
\frac{
9kT_{N-1}
-kT_{N-2}
+3\Delta r\,hT_\infty
}{
8k+3\Delta r h
}.
}
\]

然后表面向外热通量写为：

\[
\boxed{
q_s=h(T_s-T_\infty).
}
\]

该通量直接进入最后一个控制体方程。

当

\[
T_\infty>T_s
\]

时：

\[
q_s<0,
\]

表示热量实际由环境流入药材，符号方向正确。

---

# 10. 表面水分 Robin 边界

题设：

\[
-D(C_s)C_r(R,t)
=
h_m[C_s-C_\infty(t)].
\]

采用同样的二阶表面导数：

\[
C_r(R)
\approx
\frac{
8C_s-9C_{N-1}+C_{N-2}
}{
3\Delta r
}.
\]

因此：

\[
-D(C_s)
\frac{
8C_s-9C_{N-1}+C_{N-2}
}{
3\Delta r
}
=
h_m(C_s-C_\infty).
\]

由于

\[
D=D(C_s),
\]

这是一个标量非线性方程。

## 10.1 推荐 Picard 迭代

初值：

\[
C_s^{(0)}=C_{N-1}.
\]

第 \(k\) 次：

\[
D_s^{(k)}=D(C_s^{(k)}),
\]

然后：

\[
\boxed{
C_s^{(k+1)}
=
\frac{
9D_s^{(k)}C_{N-1}
-D_s^{(k)}C_{N-2}
+3\Delta r h_m C_\infty
}{
8D_s^{(k)}+3\Delta r h_m
}.
}
\]

直到：

\[
|C_s^{(k+1)}-C_s^{(k)}|<\varepsilon_s.
\]

最终：

\[
\boxed{
J_s=h_m(C_s-C_\infty).
}
\]

当

\[
C_s>C_\infty
\]

时：

\[
J_s>0,
\]

表示水分由药材向外流出。

## 10.2 为什么不优先用 Newton

Q1 表面非线性只有一个标量未知量，Picard：

- 实现简单；
- 迭代透明；
- 不需要导数；
- 对国赛论文更易说明；
- 已能稳定求解当前参数区间。

没有必要为了复杂度使用 Newton。

---

# 11. 时间离散：Method of Lines + BDF

完成空间有限体积离散后，得到：

\[
\dot{\mathbf T}
=
\mathbf F_T(t,\mathbf T),
\]

\[
\dot{\mathbf C}
=
\mathbf F_C(t,\mathbf C).
\]

使用：

```python
scipy.integrate.solve_ivp(method="BDF")
```

正式基线设置：

```text
method   = BDF
rtol     = 1e-9
atol     = 1e-11
max_step = 1.0 s
```

注意：

\[
\boxed{\texttt{max\_step=1 s}\neq\text{固定时间步长为 1 s}.}
\]

BDF 内部仍为自适应步长；1 s 只是允许的最大内部步长。

严格复核可采用：

```text
rtol     = 2e-10
atol     = 2e-12
max_step = 0.5 s
```

此前复核显示时间积分误差已经明显小于空间离散误差，因此后续精度提升应优先加密空间网格，而不是继续无意义地压缩时间步。

# 12. 为什么不采用显式有限差分作为主方法

热扩散率：

\[
\alpha
=
\frac{k}{\rho c_p}
=
\frac{0.36}{820\times2600}
\approx1.689\times10^{-7}\ {\rm m^2/s}.
\]

若使用细网格，显式稳定时间步随

\[
\Delta r^2
\]

快速减小。

例如 \(N=640\) 时：

\[
\Delta r
=
\frac{0.02}{640}
=
3.125\times10^{-5}\ {\rm m},
\]

显式热扩散稳定步长进入 \(10^{-3}\) s 量级。

对于 1800 s 长时间积分，需要百万量级时间步，不划算。

因此正式方案采用 BDF。

温度：

\[
R_T
=
\left|
-kT_r(R)-h(T_s-T_\infty)

\]

水分：

\[
R_C
=
\left|
-D(C_s)C_r(R)-h_m(C_s-C_\infty)

验证时最好使用与生产边界重构**不同阶次/不同公式**的独立导数近似，避免“用同一离散式验证自己”。

温度总能量：

\[
E(t)=\sum_i\rho c_pV_iT_i.
\]

应满足：

\[
E(t)-E(0)
=
-\int_0^t A_Rq_s(\tau)\,d\tau.

\[
M(t)=\sum_iV_iC_i,
\]

应满足：

\[
M(t)-M(0)
=
-\int_0^t A_RJ_s(\tau)\,d\tau.
\]

# 18. 单步计算逻辑

## 温度 RHS

```text
输入：t, T
↓
读取 T_inf(t)
↓
计算所有内部面导热通量
↓
中心面通量 = 0
↓
二阶 Robin 重构 T_surface
↓
计算表面热通量 q_surface
↓
对每个控制体计算：
dT/dt = (左侧面积×左通量 - 右侧面积×右通量)/(rho*cp*V)
↓
返回 dT/dt
```

## 水分 RHS

```text
输入：t, C
↓
读取 C_inf(t)
↓
计算 D(C_i)
↓
调和平均得到内部面 D_face
↓
计算内部水分通量
↓
中心面通量 = 0
↓
Picard 求解 C_surface
↓
计算表面传质通量 J_surface
↓
对每个控制体计算：
dC/dt = (左侧面积×左通量 - 右侧面积×右通量)/V
↓
返回 dC/dt
```
