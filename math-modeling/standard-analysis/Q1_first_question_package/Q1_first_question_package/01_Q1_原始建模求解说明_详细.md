# 4. 几何简化与状态变量

药材为圆柱体：

\[
L=0.25\ \mathrm m,\qquad R=0.02\ \mathrm m,
\qquad \frac{L}{R}=12.5.
\]

侧面积：

\[
A_{\mathrm{side}}=2\pi RL,
\]

两端总面积：

\[
A_{\mathrm{end}}=2\pi R^2.
\]

两端面积占总表面积：

\[
\frac{A_{\mathrm{end}}}{A_{\mathrm{side}}+A_{\mathrm{end}}}
=
\frac{R}{L+R}
\approx 7.41\%.
\]

因此问题 1 推荐采用**长圆柱一维轴对称径向模型**：

\[
T=T(r,t),\qquad C=C(r,t).
\]

空间区域：

\[
0\le r\le R.
\]

这与题目只要求“到药材中心距离”上的输出方式也是一致的。

### 建模假设

题面没有明确说明烘房内空间温湿度完全均匀，也没有给轴向/周向环境分布。因此：

> 假设同一时刻药材外表面所处烘房环境可由附件 1 给出的单一 \(T_\infty(t)\)、\(C_\infty(t)\) 表示，忽略周向与轴向环境差异。

该假设必须在论文中标记为建模假设，而不是题设事实。

# 5. 集总参数法检查

## 5.1 热扩散率

\[
\alpha=\frac{k}{\rho c_p}
=
\frac{0.36}{820\times2600}
\approx1.6886\times10^{-7}\ \mathrm{m^2/s}.
\]

## 5.2 热 Biot 数

若以半径 \(R\) 作为径向特征长度：

\[
Bi_T=\frac{hR}{k}
=
\frac{25\times0.02}{0.36}
\approx1.3889.
\]

明显大于常用集总近似阈值 \(0.1\)。

因此不能把药材温度视为处处相同，必须保留径向空间变量。

> 说明：若采用体积/面积定义的特征长度，Biot 数数值会改变，但不会改变“内部温度梯度不可忽略”的结论。实现文档统一以 \(R\) 为径向 PDE 的特征尺度。

## 5.3 初始水分扩散系数

\[
D(C_0)
=
7\times10^{-9}
\exp\left(-\frac{0.89}{2.55}\right)
\approx4.9377\times10^{-9}\ \mathrm{m^2/s}.
\]

## 5.4 质传 Biot 数

\[
Bi_m=\frac{h_mR}{D(C_0)}
=
\frac{8\times10^{-7}\times0.02}
{4.9377\times10^{-9}}
\approx3.2404.
\]

同样说明水分内部梯度不可忽略。

结论：

\[
\boxed{\text{问题 1 必须采用具有空间变量 }r\text{ 的 PDE 模型。}}
\]

# 6. 温度控制方程

## 6.1 控制微元

取半径 \(r\) 到 \(r+\mathrm dr\) 的薄圆柱壳层。

体积：

\[
\mathrm dV\approx2\pi rL\,\mathrm dr.
\]

## 6.2 Fourier 定律

径向导热通量：

\[
q_r=-k\frac{\partial T}{\partial r}.
\]

## 6.3 能量守恒

\[
\text{单位时间净导热输入}
=
\text{控制体内部能增加率}.
\]

由圆柱面积 \(2\pi rL\) 随 \(r\) 变化，取极限得到：

\[
\boxed{
\rho c_p\frac{\partial T}{\partial t}
=
\frac1r
\frac{\partial}{\partial r}
\left(
rk\frac{\partial T}{\partial r}
\right)
}.
\]

第一问中 \(\rho,c_p,k\) 都是常数，因此可等价写为：

\[
\frac{\partial T}{\partial t}
=
\alpha
\left(
\frac{\partial^2T}{\partial r^2}
+
\frac1r\frac{\partial T}{\partial r}
\right),
\]

其中

\[
\alpha=\frac{k}{\rho c_p}.
\]

**实现优先保留守恒形式**，不要只围绕展开形式写程序。

# 7. 水分控制方程

题面定义：

\[
C=\text{药材水分浓度（干基含水率）},
\]

初值为：

\[
C_0=2.55\ \mathrm{kg/kg}.
\]

采用题面给定的有效扩散系数经验式：

\[
\boxed{
D(C)=7\times10^{-9}
\exp\left(-\frac{0.89}{C}\right)
}.
\]

## 7.1 Fick 定律

径向有效水分扩散通量写为：

\[
J_C=-D(C)\frac{\partial C}{\partial r}.
\]

## 7.2 守恒方程

圆柱薄壳内：

\[
\text{水分积累}
=
\text{径向流入}
-
\text{径向流出}.
\]

得到：

\[
\boxed{
\frac{\partial C}{\partial t}
=
\frac1r
\frac{\partial}{\partial r}
\left[
rD(C)\frac{\partial C}{\partial r}
\right]
}.
\]

由于 \(D\) 依赖局部状态 \(C\)，这是非线性扩散 PDE。

必须注意：

\[
\frac1r\frac{\partial}{\partial r}
\left(rD(C)C_r\right)
\neq
D(C)
\left(C_{rr}+\frac1rC_r\right)
\]

除非额外计入 \(D'(C)(C_r)^2\)。

因此数值实现应以**通量/守恒形式**为准。

# 8. 问题 1 的温度—水分耦合判断

按问题 1 的题面和附录 2：

- \(\rho,c_p,k\) 为常数；
- \(D=D(C)\)；
- \(D\) 不含 \(T\)；
- 温度方程参数不含 \(C\)。

因此：

\[
T\not\to C,\qquad C\not\to T.
\]

问题 1 不是双向热质耦合系统，而是：

\[
\boxed{\text{两个共享几何与时间轴、但数学上可独立求解的场问题}}
\]

实现上可分别求解温度 PDE 与水分 PDE。

# 10. 中心边界条件

在 \(r=0\) 处，由轴对称性：

\[
\boxed{
\left.\frac{\partial T}{\partial r}\right|_{r=0}=0
}
\]

\[
\boxed{
\left.\frac{\partial C}{\partial r}\right|_{r=0}=0
}.
\]

物理含义：轴线上不存在优先径向方向，中心处径向通量为零。

数值实现提醒：

控制方程中存在 \(1/r\)，因此 \(r=0\) 不能直接套普通内部节点公式。

若使用成熟 PDE 包，应确认其圆柱坐标网格已经正确处理中心几何。

若自行构造空间离散，应使用轴对称极限或中心控制体进行特殊处理。

# 11. 表面 Robin 边界条件

设：

\[
T_s(t)=T(R,t),\qquad C_s(t)=C(R,t).
\]

## 11.1 表面热边界

药材外法向为 \(+r\)。

内部向外导热通量：

\[
q_{\text{out}}=-kT_r(R,t).
\]

外界空气向药材表面的对流热输入：

\[
q_{\text{in}}=h[T_\infty(t)-T_s(t)].
\]

守恒要求：

\[
-q_{\text{out}}=q_{\text{in}},
\]

等价写成：

\[
\boxed{
-k\left.\frac{\partial T}{\partial r}\right|_{R}
=
h[T_s(t)-T_\infty(t)]
}
\]

或

\[
\boxed{
kT_r(R,t)=h[T_\infty(t)-T_s(t)]
}.
\]

检查：若 \(T_\infty>T_s\)，则 \(T_r(R)>0\)，温度从中心向表面升高，热量净流入药材，符号正确。

## 11.2 表面传质边界

内部向外的扩散通量：

\[
J_{\text{out}}
=
-D(C_s)C_r(R,t).
\]

对流传质模型取：

\[
J_{\text{out}}
=
h_m[C_s(t)-C_\infty(t)].
\]

因此：

\[
\boxed{
-D(C_s)
\left.\frac{\partial C}{\partial r}\right|_{R}
=
h_m[C_s(t)-C_\infty(t)]
}.
\]

检查：若 \(C_s>C_\infty\)，右侧为正，水分向外流出；此时应有 \(C_r(R)<0\)，与干燥过程一致。

# 12. 一个必须保留的题面歧义

题面明确把药材内部 \(C\) 称为“干基含水率”，初值为 \(2.55\ \mathrm{kg/kg}\)。

附件 1 中烘房水分数据也以 kg/kg 给出，但题面没有进一步提供：

- 药材表面平衡含水率关系；
- 空气湿度与药材干基含水率之间的界面换算式；
- 水蒸气分压关系；
- 吸附等温线或相平衡模型。

因此，直接在 Robin 边界中写：

\[
h_m(C_s-C_\infty)
\]

实际上隐含了一个建模假设：

> 将附件 1 中的烘房水分数据视为题目给定传质系数 \(h_m\) 所对应的“等效外界水分势”，并与药材表面 \(C_s\) 直接构成传质驱动力。

这是当前题面数据能够支持的最简闭合方式，但必须在论文中说明，不应把它伪装成题面明确给出的界面热力学关系。

除非后续附件另有明确公式，否则**不要自行引入平衡含水率、相对湿度、水蒸气分压等新的经验参数**。

| **SciPy Method of Lines** | Python ODE + 自定义守恒空间离散 | 空间几何需自己写 | 自己进入边界通量 | `BDF/Radau` 可处理刚性非线性 | 取决于空间离散 | 中 | **强备用** |
| FEniCSx + PETSc | Python/C++ FEM | 可通过轴对称弱式表达 | Robin 自然 | 强 | 强 | 较高 | 高精度验证/扩展 |
| SUNDIALS/CVODE | C/C++ ODE | 需先自行半离散 | 需自行处理 | 强 | 取决于半离散 | 较高 | C++ 团队备用 |

# 17. 【推荐主方法】FiPy 有限体积

优先让数值专家评估 **FiPy 的一维圆柱有限体积网格**。

理由：

1. 当前 PDE 都是标准扩散守恒形式；
2. 有限体积天然围绕“控制体净通量 = 储存变化”构造；
3. 与圆柱几何面积因子匹配；
4. 水分方程的 \(D(C)\) 最适合以面通量处理；
5. 后续做能量/质量整体守恒检查更直观；
6. 避免自行编写完整 PDE 求解器。

建议任务顺序：

1. 先用 FiPy 解温度线性问题；
2. 验证中心边界与表面 Robin 热边界；
3. 再实现水分非线性扩散；
4. 每个时间步/非线性迭代更新 \(D(C)\)；
5. 检查表面 Robin 传质通量；
6. 做网格和时间精度检查。

### FiPy 方案的关键风险

Robin 边界不能只“看起来像对”，必须通过通量方向和守恒残差验证。

如果 FiPy 对当前 Robin 表达导致实现过度绕曲，不要为了坚持工具而写复杂技巧，应切换到下面的 Method of Lines 方案。

---

# 18. 【备用方法】守恒型有限体积半离散 + SciPy `solve_ivp`

如果 FiPy 的边界条件实现不够透明，建议使用：

\[
\boxed{
\text{一维守恒型有限体积空间半离散}
+
\text{SciPy solve\_ivp}
}
\]

时间积分优先：

- `method="BDF"`；
- 或 `method="Radau"`。

原因：

- 水分方程存在非线性变系数；
- 使用成熟隐式刚性 ODE 积分器比自行写时间推进器更稳妥；
- 数值专家只需要自行构造“控制体通量到状态导数”的 RHS；
- 不需要自行实现 Newton 时间积分框架。

该方案虽然空间离散需要自己建立，但**时间积分仍由成熟库负责**，是“透明性”和“成熟求解器”之间很好的折中。

# 19. 不建议的主方案

## 19.1 不建议直接用显式 Euler

不是说一定算不了，而是：

- 稳定时间步受空间步长和最大扩散率约束；
- 非线性 \(D(C)\) 会使稳定性判断更繁琐；
- 用户要求每 1 s 输出，不代表积分时间步就是 1 s；
- 没必要放弃成熟隐式积分器。

## 19.2 不建议把 \(D(C)\) 固定为 \(D(C_0)\)

可以作为程序验证的线性基准算例，但不能作为正式主模型。

正式模型必须按：

\[
D=D(C(r,t))
\]

更新。

## 19.3 不建议把药材表面直接设为环境值

不能直接设置：

\[
T(R,t)=T_\infty(t)
\]

或

\[
C(R,t)=C_\infty(t).
\]

题目明确给了 \(h\) 和 \(h_m\)，说明表面需要保留有限对流阻力，即 Robin 边界。

# 22. 结果合理性检查

## 22.1 温度最大值原则

当前模型无体热源，初始温度为 28°C，环境温度在问题 1 区间从 28°C 上升至 41.513°C。

因此计算结果不应出现明显超出边界/初值控制范围的非物理温度过冲。

通常应满足：

- 表层先升温；
- 中心后升温；
- 在加热阶段，径向上温度通常由中心向表面升高。

## 22.2 水分方向

问题 1 中：

\[
C_0=2.55,
\]

而附件环境水分值约为 \(0.02\sim0.033\)。

按当前 Robin 建模假设，驱动力始终指向药材外部，因此应表现为：

- 表面含水率先下降；
- 内部下降滞后；
- 中心通常保持最高含水率。

如果得到表面水分高于中心并持续增强，需要首先检查 Robin 符号和通量方向。

## 22.3 正值性

必须保证：

\[
C(r,t)>0,
\qquad
D(C)>0.
\]

如果数值方法产生负含水率，属于数值失败，不应通过事后绝对值或人工裁剪掩盖。

# 23. 守恒检查

即使使用成熟包，也建议做积分级守恒残差。

## 23.1 热量

验证域内总显热变化率与表面对流热通量的一致性。

定性形式：

\[
\frac{\mathrm d}{\mathrm dt}
\int_0^R
\rho c_pT\,2\pi rL\,\mathrm dr
\]

应与表面输入：

\[
2\pi RL\,h[T_\infty-T_s]
\]

一致到数值误差范围。

当前一维模型忽略端面，因此守恒检查只对侧壁模型本身成立。

## 23.2 水分

验证：

\[
\frac{\mathrm d}{\mathrm dt}
\int_0^R
C\,2\pi rL\,\mathrm dr
\]

与表面传质通量对应。

由于 \(C\) 是干基质量比，这里主要用于检查**数值守恒结构**；若要解释成绝对水质量，还需要干固体质量/基准密度定义，而题面当前没有单独提供该信息，不能自行补造。

# 30. 最终建议

问题 1 的代码实现应围绕下列核心模型展开：

\[
\boxed{
\rho c_p T_t
=
\frac1r(rkT_r)_r
}
\]

\[
\boxed{
C_t
=
\frac1r[rD(C)C_r]_r
}
\]

配合：

\[
T_r(0,t)=0,\qquad C_r(0,t)=0,
\]

\[
-kT_r(R,t)
=
h[T(R,t)-T_\infty(t)],

\[
-D(C_s)C_r(R,t)
=
h_m[C_s-C_\infty(t)].
\]

推荐求解策略：

\[
\boxed{\text{FiPy 有限体积作为首选}}

\[
\boxed{
\text{守恒型有限体积空间半离散}

\text{SciPy BDF/Radau}
}

作为主力备用。

D(C)\text{ 非线性更新}

\text{收敛与守恒验证}

这五部分。
