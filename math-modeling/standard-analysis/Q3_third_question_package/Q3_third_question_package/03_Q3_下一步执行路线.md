# 2. 第一优先级：修正 heat balance 诊断

当前 Notebook：

```text
Heat instantaneous max relative residual = 1.0
```

不能直接用于论文。

问题不是 PDE，而是长期近稳态时：

\[
S\approx0,\qquad Q\approx0,
\]

逐点相对残差：

\[
|S+Q|/\max(|S|,|Q|)
\]

发生近零分母失效。

## 应增加两个诊断量

### 绝对残差

\[
R_{\rm heat,abs}(t)
=
\left|
\sum_i\rho_ic_{p,i}V_i\dot T_i+A_Rq_R
\right|.
\]

### 全局归一化残差

\[
\boxed{
R_{\rm heat,global}
=
\frac{
\max_tR_{\rm heat,abs}(t)
}{
\max_t
\max(
|\sum_i\rho_ic_{p,i}V_i\dot T_i|,
|A_Rq_R|
)
}.
}
\]

## 验收

确认：

- 绝对 residual 很小；
- 全局归一化 residual 达到预期小量级；
- 后期热通量趋近零时不再产生虚假的 1.0。

# 4. 第三优先级：正式事件时间网格收敛

这是 Q3 最重要的数值收敛验证。

正式打开：

```python

```

使用 production-like 配置：

```text

```

运行：

\[

N=320,\quad640,\quad1280
}
\]

记录：

\[
t_{\rm dry}^{320},
\quad
t_{\rm dry}^{640},
\quad
t_{\rm dry}^{1280}.
\]

计算：

\[
E_t^{320,640}
=
|t_{\rm dry}^{640}-t_{\rm dry}^{320}|,
\]

\[
E_t^{640,1280}
=
|t_{\rm dry}^{1280}-t_{\rm dry}^{640}|.
\]

若差值明显缩小，可计算观测阶：

\[
p
=
\log_2
\left(
\frac{E_t^{320,640}}
{E_t^{640,1280}}
\right).
\]

## 论文优先展示

这张事件时间收敛表比普通固定时刻场误差更适合 Q3。
