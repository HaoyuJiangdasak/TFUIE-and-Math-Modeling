# 1. 问题 3 的数值本质

第三问不是简单把第二问多积分若干时间，而是要确定：

\[
\boxed{
t_{\rm dry}
=
\inf\left\{
t>0:
\max_{0\le r\le R}C(r,t)\le0.15
\right\}.
}
\]

因此 Q3 的数值核心有三项：

1. 长时间积分；
2. 4 h 后环境边界的合理延拓；
3. 首次阈值穿越时间的高精度事件检测。

第二问已经验证的固定域 PDE/FVM 内核应直接继承，不重新建模。

# 2. 继承 Q2 的完整 PDE 内核

温度方程：

\[
\rho(C)c_p(C)\frac{\partial T}{\partial t}
=
\frac1r
\frac{\partial}{\partial r}
\left(
rk(C)\frac{\partial T}{\partial r}
\right).
\]

水分方程：

\[
\frac{\partial C}{\partial t}
=
\frac1r
\frac{\partial}{\partial r}
\left[
rD(C,T)\frac{\partial C}{\partial r}
\right].
\]

物性仍使用第二问经验公式：

\[
\rho=\rho(C),
\qquad
c_p=c_p(C),
\qquad
k=k(C),
\qquad
D=D(C,T).
\]

其中 \(D\) 的温度必须使用：

\[
T_K=T_C+273.15.
\]

问题 3 不引入问题 4 的尺寸收缩，因此：

\[
\boxed{R=0.02\ {\rm m}}
\]

保持不变。

# 3. 空间离散：完全继承 Q2

仍采用圆柱 cell-centered 有限体积法。

控制体面：

\[
r_j^f=j\Delta r,
\qquad
j=0,\ldots,N,
\]

单元中心：

\[
r_i=\left(i+\frac12\right)\Delta r,
\qquad
i=0,\ldots,N-1,
\]

其中：

\[
\Delta r=\frac RN.
\]

内部热通量：

\[
q_{i+1/2}
=
-k_{i+1/2}
\frac{T_{i+1}-T_i}{\Delta r},
\]

内部水分通量：

\[
J_{i+1/2}
=
-D_{i+1/2}
\frac{C_{i+1}-C_i}{\Delta r}.
\]

正式仍使用调和平均：

\[
k_f=\frac{2k_Lk_R}{k_L+k_R},
\qquad
D_f=\frac{2D_LD_R}{D_L+D_R}.
\]

# 4. 中心 \(r=0\) 的处理

\[

\[
q_0=0,\qquad J_0=0.

程序中不直接计算：

\[
1/r.

\[
\boxed{

}
\]

# 5. 表面 Robin：继续采用局部联立 Picard

热 Robin：

\[
-k(C_s)T_r(R)
=
h(T_s-T_\infty).
\]

水分 Robin：

\[
-D(C_s,T_s)C_r(R)
=
h_m(C_s-C_\infty).
\]

继续使用二阶表面导数：

\[
T_r(R)
\approx
\frac{8T_s-9T_{N-1}+T_{N-2}}{3\Delta r},
\]

\[
C_r(R)
\approx
\frac{8C_s-9C_{N-1}+C_{N-2}}{3\Delta r}.
\]

因此：

\[
T_s\leftrightarrow C_s
\]

构成一个局部非线性耦合问题。

正式算法仍以局部 Picard 为主：

\[
C_s^{(m)}
\rightarrow
k_s^{(m)}
\rightarrow
T_s^{(m+1)}
\rightarrow
D_s^{(m+1)}
\rightarrow
C_s^{(m+1)}.
\]

# 6. Q3 的低含水率表面非线性问题

第三问积分到：

\[
C\approx0.15
\]

附近，远低于第二问的含水率范围。

实际开发过程中发现：

> 很粗网格下，局部 Robin 固定点 Picard 在低含水率阶段可能失去收缩性。

同时，离散 Robin 方程可能出现多个数学根。

因此 Q3 实现中增加了一个**安全兜底**：

1. 正式仍优先使用局部 Picard；
2. 若 Picard 在规定迭代数内不收敛；
3. 求解同一个局部 Robin 固定点方程；
4. 选择与近表面内部状态连续的高含水/最大物理解分支；
5. 记录 fallback 调用次数。

这不是修改 PDE 或 Robin 条件，只是替换局部非线性方程的求解方式。

最重要的是：

### 正式 \(N=1280\) 生产解

实际统计：

- surface calls：32496；
- 平均 Picard 迭代：约 7.63；
- 最大 Picard 迭代：28；
- Brent fallback：
  \[
  \boxed{0}
  \]

即：

\[
\boxed{
N=1280\text{ 正式解全程由局部 Picard 自身收敛。}
}
\]

因此 fallback 不影响最终生产结果。

# 17. 为什么后期越来越慢

第二问经验公式导致：

\[
C\downarrow
\Rightarrow
D(C,T)\downarrow.
\]

在约 \(50^\circ C\)：

\[
D(C=2.55)
\approx
1.35\times10^{-8}\ {\rm m^2/s},
\]

而：

\[
D(C=0.15)
\approx
8.0\times10^{-10}\ {\rm m^2/s}.
\]

相差约：

\[
\boxed{16.8\text{ 倍}}.
\]

因此长期过程自然呈现：

\[
\boxed{
\text{前期较快}
\rightarrow
\text{后期明显长尾}
}
\]

这与 57 h 量级的最终时间在当前模型内相一致。

# 20. 当前热平衡诊断有一个验证代码问题

最新 Notebook 打印：

\[
\boxed{
\text{Heat instantaneous max relative residual}=1.0.
}
\]

这个数值**不能解释为热方程求解失败**。

当前热离散式本身满足通量望远镜求和：

\[
\sum_i
\rho_i c_{p,i}V_i\dot T_i
+
A_Rq_R
=0
\]

至离散舍入精度。

问题在于长期后期：

\[
T\rightarrow T_{\infty,\rm long},
\]

于是热储存项和表面热通量都趋近：

\[
0.
\]

若逐时刻用：

\[
\frac{|S+Q|}
{\max(|S|,|Q|)}
\]

归一化，分母本身接近机器零，就可能出现相对值约 1。

因此当前 Notebook 的 `1.0` 是**近零量归一化失效的诊断问题**。

正式验证应改成：

\[
R_{\rm abs}
=
|S+Q|,
\]

并采用全时域统一尺度：

\[
\boxed{
R_{\rm global}
=
\frac{
\max_t|S(t)+Q(t)|
}{
\max_t\max(|S(t)|,|Q(t)|)
}.
}
\]

或者在热通量小于全局峰值某阈值时不计算逐点相对残差。
