# 1. 问题 2 的直接目标

问题 2 要求建立整个烘干过程中药材内部温度与水分浓度的变化规律，并输出前 3 h 内指定时刻、指定径向位置的结果。

状态变量：

\[
T=T(r,t),
\qquad
C=C(r,t),
\]

其中：

- \(T(r,t)\)：药材内部温度；
- \(C(r,t)\)：题面称“水分浓度”，实际定义为**干基含水率**，单位 kg/kg；
- \(r\)：到圆柱轴线的径向距离；
- \(t\)：烘干时间。

问题 2 的数学本质为：

\[
\boxed{
\text{固定区域上的变系数、非线性、双向热—湿耦合 PDE 初边值问题}
}
\]

# 6. 双向热—湿耦合机制

问题 2 的耦合链为：

\[
\boxed{
C\rightarrow\rho,c_p,k\rightarrow T
}
\]

以及：

\[
\boxed{
T,C\rightarrow D\rightarrow C
}
\]

## 6.1 \(\rho(C)\)

\[
\rho(C)=650+128C,
\qquad
\frac{d\rho}{dC}=128>0.
\]

所以：

\[
\boxed{C\downarrow\Rightarrow\rho\downarrow}
\]

## 6.2 \(c_p(C)\)

\[
c_p(C)=1450+2736\frac{C}{C+1},
\]

\[
\frac{dc_p}{dC}
=
\frac{2736}{(C+1)^2}>0.
\]

所以：

\[
\boxed{C\downarrow\Rightarrow c_p\downarrow}
\]

## 6.3 \(k(C)\)

\[
k(C)=0.21+0.38\frac{C}{C+1},
\]

\[
\frac{dk}{dC}
=
\frac{0.38}{(C+1)^2}>0.
\]

所以：

\[
\boxed{C\downarrow\Rightarrow k\downarrow}
\]

## 6.4 \(D(C,T)\) 的温度影响

\[
\ln D
=
\ln(2.4\times10^{-3})
-\frac{0.45}{C}
-\frac{3850}{T_K}.
\]

\[
\frac{\partial\ln D}{\partial T_K}
=
\frac{3850}{T_K^2}>0.
\]

因此：

\[
\boxed{T\uparrow\Rightarrow D\uparrow}
\]

## 6.5 \(D(C,T)\) 的含水率影响

\[
\frac{\partial\ln D}{\partial C}
=
\frac{0.45}{C^2}>0.
\]

因此：

\[
\boxed{C\downarrow\Rightarrow D\downarrow}
\]

于是存在竞争：

\[
T\uparrow\Rightarrow D\uparrow,
\qquad
C\downarrow\Rightarrow D\downarrow.
\]

最终 \(D(r,t)\) 的实际变化必须通过计算判断，不能提前预设。

# 7. 温度控制方程

问题 2 推荐保留守恒型变导热率形式：

\[
\boxed{
\rho(C)c_p(C)
\frac{\partial T}{\partial t}
=
\frac1r
\frac{\partial}{\partial r}
\left[
rk(C)\frac{\partial T}{\partial r}
\right]
}
\]

## 7.1 为什么不能写成 \(T_t=\alpha(C)\nabla^2T\)

因为：

\[
k=k(C(r,t)).
\]

展开：

\[
\frac1r(rkT_r)_r
=
k\left(T_{rr}+\frac1rT_r\right)
+
\frac{dk}{dC}C_rT_r.
\]

简单写成：

\[
T_t=\frac{k(C)}{\rho(C)c_p(C)}
\left(T_{rr}+\frac1rT_r\right)
\]

会漏掉空间变导热率对应的通量项。

因此：

\[
\boxed{
\text{必须优先保留 } \frac1r(rkT_r)_r
}
\]

## 7.2 左侧的物理层次

国赛主模型把：

\[
\rho(C)c_p(C)
\]

视为局部**表观体积热容**。

更严格的能量守恒应从焓 \(H(T,C)\) 出发，并可能涉及：

- 水分携带焓；
- 蒸发潜热；
- 相变速率；
- 多相热输运。

题目未提供这些闭合参数。

因此主模型使用：

\[
\boxed{
\rho(C)c_p(C)T_t=\nabla\cdot[k(C)\nabla T]
}
\]

是基于题设数据闭合性的合理简化。

## 7.3 潜热处理

主模型**不加入潜热项**。

理由不是“实际没有潜热”，而是：

> 题目没有提供汽化潜热、相变速率、相平衡关系等必要信息，无法建立可闭合的潜热模型。

# 8. 水分控制方程

题面变量 \(C\) 是干基含水率。

主模型将题给的：

\[
D(C,T_K)
\]

解释为以干基含水率为状态变量的**有效扩散系数**。

由 Fick 型有效通量：

\[
J_C=-D(C,T_K)\frac{\partial C}{\partial r}
\]

和圆柱壳层质量守恒，得到：

\[
\boxed{
\frac{\partial C}{\partial t}
=
\frac1r
\frac{\partial}{\partial r}
\left[
rD(C,T_K)\frac{\partial C}{\partial r}
\right]
}
\]

因为 \(D=D(C,T)\)，这是非线性变系数扩散 PDE。

不能直接写：

\[
C_t=D(C,T)
\left(C_{rr}+\frac1rC_r\right)
\]

而忽略 \(D\) 的空间梯度贡献。

## 8.1 更严格的干基质量守恒

若定义单位体积绝干固体质量 \(\rho_d\)，严格形式可以写为：

\[
\frac{\partial(\rho_dC)}{\partial t}
=
\frac1r
\frac{\partial}{\partial r}
\left[
r\rho_dD(C,T)C_r
\right].
\]

但题目没有明确给：

- 干固体密度；
- 孔隙率；
- 固体骨架体积分数；
- 固体运动；
- 收缩关系。

因此不能把题面的整体材料密度 \(\rho(C)\) 机械当成 \(\rho_d\)。

主模型仍采用有效含水率扩散方程。

# 11. 表面热 Robin 边界

设：

\[
T_s=T(R,t),
\qquad
C_s=C(R,t).
\]

表面内部 Fourier 通量：

\[
q_{\rm out}=-k(C_s)T_r(R,t).
\]

表面对流换热：

\[
q_{\rm out}=h[T_s-T_\infty(t)].
\]

因此：

\[
\boxed{
-k(C_s)T_r(R,t)
=
h[T_s-T_\infty(t)]
}
\]

其中表面导热系数取：

\[
\boxed{k_s=k(C_s)}
\]

---

# 12. 表面传质 Robin 边界

表面扩散率：

\[
\boxed{
D_s=D(C_s,T_{K,s})
}
\]

其中：

\[
T_{K,s}=T_s+273.15.
\]

表面向外扩散通量：

\[
J_{\rm out}
=
-D_sC_r(R,t).
\]

对流传质通量：

\[
J_{\rm out}
=
h_m[C_s-C_\infty(t)].
\]

所以：

\[
\boxed{
-D(C_s,T_{K,s})C_r(R,t)
=
h_m[C_s-C_\infty(t)]
}
\]

若 \(C_s>C_\infty\)，右端为正，对应水分流出，符号正确。

# 19. 非线性耦合的推荐迭代框架

如果不直接做全耦合 Newton，建议先采用分块 Picard。

每个时间层 \(t_n\to t_{n+1}\)：

### Step 1：预测

\[
T_{n+1}^{(0)}=T_n,
\qquad
C_{n+1}^{(0)}=C_n.
\]

### Step 4：更新扩散率

\[
D^{(m+1)}
=

\]

### Step 5：求水分

求：

\[
C^{(m+1)}.
\]

### Step 6：检查收敛

同时检查：

\[
\|T^{(m+1)}-T^{(m)}\|
\]

与：

\[
\|C^{(m+1)}-C^{(m)}\|.

具体范数与容差由数值专家通过四位小数稳定性测试确定。

- 减小时间步；
- 使用欠松弛；
- 再考虑 Newton / 全耦合算法。

# 25. 最容易被评委质疑的 5 个问题

## 1. 为什么沿用 Q1 的 \(h,h_m\)？

答：Q2 附录未重新给出表面对流系数，为闭合 Robin 边界，在同一烘干设备假设下继承 Q1 数值；这是**必要继承假设**。

## 2. \(C\) 是干基含水率，为什么使用 Fick 方程？

答：将题给 \(D(C,T)\) 理解为针对干基含水率状态建立的有效扩散率。严格干基质量守恒需要干固体密度等额外信息，题目未提供。

## 3. 为什么不用完整焓方程？

答：完整焓模型需要水分焓、潜热、相变速率等题面未提供的闭合数据。主模型采用题给有效物性构造表观热容模型。

## 4. 为什么不设置预热/恒温硬切换？

答：附件 1 完整覆盖 3 h，边界是连续实测数据；阶段划分用于解释，不应无依据覆盖已知数据。

## 5. 为什么不考虑收缩？

答：尺寸变化被题目单独安排在问题 4。Q2 保持固定半径，可作为后续收缩模型的对照基准。

\left[

\right]

=

\[
T_r(0,t)=0,
\qquad

-D(C_s,T_{K,s})C_r(R,t)

一句话概括：
