# 1. 问题 2 相比问题 1 的核心变化

问题 1 中，热物性基本固定，温度场与水分场可以近似分开求解。

问题 2 中，材料参数随状态变化：

\[
\rho=\rho(C),
\qquad
c_p=c_p(C),
\qquad
k=k(C),
\]

并且：

\[
D=D(C,T).
\]

因此存在：

\[
C
\rightarrow
\rho,c_p,k
\rightarrow
T,
\]

以及：

\[
T,C
\rightarrow
D
\rightarrow
C.
\]

于是问题 2 形成一个**非线性、变系数、双向参数耦合的抛物型扩散系统**。

需要强调：

- 这里的“耦合”主要来自物性参数依赖；
- 模型中没有显式加入蒸发潜热、吸附热、相变焓等热力学耦合项；
- 因此论文中更准确的说法是：

\[
\boxed{\text{变物性耦合热湿传递模型}}
\]

而不是“完整热湿热力学耦合模型”。

# 3. 控制方程

温度方程：

\[
\rho(C)c_p(C)
\frac{\partial T}{\partial t}
=
\frac1r
\frac{\partial}{\partial r}
\left[
rk(C)\frac{\partial T}{\partial r}
\right].
\]

水分方程：

\[
\frac{\partial C}{\partial t}
=
\frac1r
\frac{\partial}{\partial r}
\left[
rD(C,T)\frac{\partial C}{\partial r}
\right].
\]

其中：

\[
D(C,T)
=
2.4\times10^{-3}
\exp(-0.45/C)
\exp\left[
-\frac{3850}{T_K}
\right],
\]

且：

\[
\boxed{
T_K=T(^\circ{\rm C})+273.15.
}
\]

Kelvin 转换是 Q2 最关键的实现检查之一。

# 4. 为什么正式采用联合 BDF

原始建模交接方案中，手工分块 Picard 是一个正确且透明的方法。

但正式计算采用联合状态：

\[
\mathbf y=
[T_0,\ldots,T_{N-1},
C_0,\ldots,C_{N-1}]^T.
\]

建立：

\[
\dot{\mathbf y}
=
\mathbf F(t,\mathbf y).
\]

每次 BDF 调用 RHS 时，都根据当前：

\[
T,\ C
\]

重新更新：

\[
\rho(C),\quad
c_p(C),\quad
k(C),\quad
D(C,T).
\]

因此不会产生“在一个时间层内冻结物性”的显式参数滞后。

相对于：

\[
(C^n,T^n)
\rightarrow
k^n,D^n
\rightarrow
T^{n+1}
\rightarrow
C^{n+1},
\]

联合 BDF 能更自然地处理状态之间的耦合，也避免人为的温度—水分分裂顺序误差。

# 5. 空间离散：继承 Q1 的圆柱有限体积框架

继续采用 cell-centered finite volume method。

控制体面：

\[
r_j^f=j\Delta r,
\qquad
j=0,\ldots,N.
\]

单元中心：

\[
r_i=
\left(i+\frac12\right)\Delta r,
\qquad
i=0,\ldots,N-1.
\]

其中：

\[
\Delta r=\frac RN.
\]

圆柱面面积：

\[
A_j=2\pi Lr_j^f.
\]

控制体体积：

\[
V_i=
\pi L
\left[
(r_{i+1}^f)^2
-
(r_i^f)^2
\right].
\]

所有控制方程均写成：

\[
\text{储存项变化}
=
\text{左侧通量}
-
\text{右侧通量}.
\]

# 6. 温度内部面通量

单元内：

\[
k_i=k(C_i).
\]

内部面导热系数采用调和平均：

\[
\boxed{
k_{i+1/2}
=
\frac{2k_i k_{i+1}}
{k_i+k_{i+1}}
}
\]

内部热通量：

\[
q_{i+1/2}
=
-k_{i+1/2}
\frac{T_{i+1}-T_i}{\Delta r}.
\]

控制体方程：

\[
\rho_i c_{p,i}V_i
\frac{dT_i}{dt}
=
A_i q_i
-
A_{i+1}q_{i+1}.
\]

即：

\[
\boxed{
\frac{dT_i}{dt}
=
\frac{
A_i q_i-A_{i+1}q_{i+1}
}{
\rho_i c_{p,i}V_i
}.
}
\]

其中：

\[
\rho_i=\rho(C_i),
\]

\[
c_{p,i}=c_p(C_i).
\]

---

# 7. 水分内部面通量

单元内：

\[
D_i=D(C_i,T_i).
\]

内部面扩散系数采用调和平均：

\[
\boxed{
D_{i+1/2}
=
\frac{2D_iD_{i+1}}
{D_i+D_{i+1}}.
}
\]

扩散通量：

\[
J_{i+1/2}
=
-D_{i+1/2}
\frac{C_{i+1}-C_i}{\Delta r}.
\]

控制体方程：

\[
V_i\frac{dC_i}{dt}
=
A_iJ_i-A_{i+1}J_{i+1}.
\]

即：

\[
\boxed{
\frac{dC_i}{dt}
=
\frac{
A_iJ_i-A_{i+1}J_{i+1}
}{
V_i
}.
}
\]

必须保持：

\[
\nabla\cdot(D\nabla C)
\]

的守恒通量结构，不能把 \(D\) 简单提到算子外。

# 13. 二阶表面水分 Robin

采用：

\[
C_r(R)
\approx
\frac{
8C_s-9C_{N-1}+C_{N-2}
}{
3\Delta r
}.
\]

Robin：

\[
-D(C_s,T_s)C_r(R)

# 14. 表面局部联立 Picard

正式使用局部耦合 Picard。

初值可取：

\[
C_s^{(0)}=C_{N-1},
\]

\[
T_s^{(0)}=T_{N-1}.
\]

第 \(m\) 次：

\[
C_s^{(m)}
\rightarrow
k_s^{(m)}
\rightarrow
T_s^{(m+1)}
\]

然后：

\[
(C_s^{(m)},T_s^{(m+1)})
\rightarrow
D_s^{(m)}
\rightarrow
C_s^{(m+1)}.
\]

直到：

\[
|T_s^{(m+1)}-T_s^{(m)}|
<\varepsilon_T,
\]

并且：

\[
|C_s^{(m+1)}-C_s^{(m)}|
<\varepsilon_C.
\]

实际生产解中：

- 平均 Picard 次数约为 4；
- 最大迭代次数为 5。

因此：

\[
\boxed{
\text{当前局部联立 Picard 收敛稳定，成本很低。}
}
\]

# 17. 为什么不采用参数滞后作为正式方案

一种简单方法是：

\[
C^n,T^n
\rightarrow
\rho^n,c_p^n,k^n,D^n
\rightarrow
T^{n+1}
\rightarrow
C^{n+1}.
\]

它的优点是实现简单。

缺点是：

- 物性只使用旧时间层；
- 存在参数滞后；
- 温度与水分存在人工求解顺序；
- 会产生分裂误差。

实际辅助实验中，在：

\[
N=160,
\qquad
\Delta t=30s
\]

下，单次滞后方案与充分收敛的 Picard 结果之间最大差异约：

\[
\Delta T_{\max}
=
0.004339^\circ C,
\]

\[
\Delta C_{\max}
=
2.28\times10^{-4}.
\]

因此正式结果不采用参数单次冻结。

# 22. Q2 热平衡验证不能直接照搬 Q1

这是一个非常重要的数学问题。

Q1 中：

\[
\rho,\ c_p
\]

为常数，可以比较累计内部热量变化与累计表面热通量。

Q2 中：

\[
\rho=\rho(C),
\qquad
c_p=c_p(C).
\]

如果定义：

\[
E=\int \rho(C)c_p(C)T\,dV,
\]

则：

\[
\frac{dE}{dt}
=
\int \rho c_pT_t\,dV
+
\int
T\frac{d(\rho c_p)}{dC}C_t\,dV.
\]

而当前 PDE 只包含：

\[
\rho c_pT_t
=
\nabla\cdot(k\nabla T).
\]

因此不能宣称：

\[
\frac{d}{dt}
\int\rho c_pT\,dV
=
-\text{表面热通量}.
\]

与数值结果高度一致。

所以：

\[
\boxed{
\text{最初几秒的表面快速失水是合理的初始边界层响应。}
}
\]

# 28. 后期极小温度反转的解释

在后期环境温度曲线存在微小非单调变化。

因此某些时刻，表面温度可能比稍内侧温度低约：

\[
0.004^\circ C
\]

量级。

这不是数值振荡，而是外界温度轻微回落时表面率先响应。

因此不要强制：

\[
T(r,t)
\]

在所有时刻都严格随半径单调增加。

水分场则保持从中心到表面单调下降，没有发现明显异常。

# 31. 最容易写错的地方

1. Q2 错误接续 Q1 在 1800 s 的状态；
2. \(D(C,T)\) 中把 Celsius 直接放进 Arrhenius 指数；
3. 每个 BDF 步只更新一次物性；

5. \(k_f,D_f\) 内部面计算错误；

7. Robin 符号写反；
8. \(r=0\) 直接出现 \(1/r\)；
9. 用 `clip` 隐藏负水分；
10. 把 `max_step=5 s` 误写成固定时间步长；
