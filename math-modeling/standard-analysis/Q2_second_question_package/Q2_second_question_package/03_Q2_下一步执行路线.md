# 7. 第六优先级：整理半离散平衡

## 热方程

检查：

\[
\sum_i
\rho_i c_{p,i}V_i\dot T_i
+
A_Rq_R
\approx0.
\]

当前残差约：

\[

\]

## 水分方程

检查：

\[
\sum_iV_i\dot C_i
+
A_RJ_R
\approx0.
\]

\[
1.8\times10^{-16}.
\]

累计含水率积分—表面通量相对误差：

\[
\approx2\times10^{-7}.
\]

### 论文措辞

热方程写：

> 半离散热通量平衡。

水分写：

> 含水率积分与表面扩散通量一致性。

不要把 Q2 热验证写成 Q1 常物性情况下的“累计热能变化 = 表面累计热通量”。

## 13.2 后期极小温度反转

环境温度数据不是严格单调。

在约 2.9 h 左右，靠近表面的局部温度可能出现约：

\[
0.004^\circ C
\]

量级的径向反转。

这属于真实时变边界响应，不是数值振荡。

因此：

\[
\boxed{
\text{不能把“温度径向严格单调”作为 Q2 的硬约束。}
}
\]

应该检查的是：

- 反转是否与环境温度回落同步；
- 数值幅度是否很小；
- 网格加密后是否稳定存在；
- 是否无异常振荡。

当前结果满足这些特征。
