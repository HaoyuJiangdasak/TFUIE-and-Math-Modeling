# 1. 问题 3 的数学本质

题目要求：

\[
\text{药材各处水分浓度均低于 }0.15\ \mathrm{kg/kg}.
\]

因此 Q3 不是“再建立一个新模型”，而是：

\[
\boxed{
\text{Q2 非线性耦合 PDE 长期积分}
+
\text{长期环境边界构造}
+
\text{全空间阈值事件检测}
}
\]

最终主要输出：

\[
\boxed{t_{\rm dry}}
\]

即首次满足全域水分阈值的烘干时间。

虽然题目最终只要求输出水分浓度，但 Q2 中：

\[
D=D(C,T),
\]

所以温度仍通过：

\[
T\rightarrow D\rightarrow C
\]

影响水分扩散。因此：

\[
\boxed{
\text{Q3 必须长期同步求解 }T(r,t)\text{ 与 }C(r,t)
}
\]

不能因为 Q3 只要求输出水分，就停止求解温度方程。

# 5. Q3 是从 \(t=0\) 重算，还是接续 Q2？

数学上，Q3 的模型可从：

\[

\]

一直积分到 \(t_{\rm dry}\)。

数值实现时有两种方式。

## 方案 A：从 \(t=0\) 完整积分

优点：

- 最直接；
- 不依赖中间文件；
- 避免状态传递误差。

如果 Q2 程序保存了：

\[
T(r,10800),\qquad C(r,10800)
\]

的**内部全精度状态**，可直接从 3 h 继续积分。

这与从 \(t=0\) 重算在理论上等价。

### 禁止直接使用四舍五入输出

不建议使用 `result2.xlsx` 中已经保留四位小数的值作为 Q3 重启初值。

如果没有全精度 checkpoint：

\[
\boxed{
\text{建议从 }t=0\text{ 重算}
}
\]

# 12. 事件函数

定义：

\[
\boxed{
g(t)=C_{\max}(t)-0.15
}
\]

烘干前：

\[
g(t)>0.
\]

第一次达到阈值附近：

\[
g(t)=0.

达标以后：

\[
g(t)<0.
\]

数值上应寻找：

\[
\boxed{
g(t)=0
}
\]

的第一次**向下穿越**。

# 13. 中心能否直接代表最慢干燥位置？

物理上通常预期中心最湿，因为：

- 表面直接发生传质；
- 内部扩散路径更长；
- 中心距排湿边界最远。

但这一点不能未经验证就直接变成终止判据。

数值计算过程中应监测：

\[
\boxed{
r_{\max}(t)
=
\operatorname*{argmax}_{0\le r\le R}C(r,t)
}
\]

只有在全过程验证：

\[
r_{\max}(t)=0
\]

或最大值始终位于中心邻域后，才能进一步解释为：

\[
\boxed{
C_{\max}(t)=C(0,t)
}
\]

从而得出：

> 最终烘干时间由中心区域控制。

# 14. 中心位置的数值注意事项

若使用节点型有限差分且包含 \(r=0\) 节点，可直接比较全部节点。

若使用 cell-centered 有限体积，第一控制体中心通常位于：

\[
r=\frac{\Delta r}{2},
\]

并不是真正的 \(r=0\)。

此时建议：

1. 事件主判据仍以全网格最大值为基础；
2. 必要时利用中心对称性重构 \(C(0,t)\)；
3. 用网格加密验证 \(t_{\rm dry}\) 对中心处理是否收敛。

# 16. 推荐的事件检测流程

## Step 1：长期积分并监测事件函数

持续计算：

\[
g(t)=C_{\max}(t)-0.15.
\]

## Step 2：找到第一次变号区间

找到：

\[
g(t_a)>0,
\]

\[
g(t_b)<0.
\]

则：

\[
t_{\rm dry}\in(t_a,t_b).
\]

## Step 3：保存 \(t_a\) 的全精度状态

保存：

\[
T(r,t_a),\qquad C(r,t_a).
\]

## Step 4：局部重积分

在：

\[
[t_a,t_b]
\]

内使用更小 `max_step` 或更严格时间容差。

## Step 5：零点定位

优先：

1. 求解器内置事件检测；
2. Brent / 二分等根查找；
3. 时间步加密；
4. 平滑情况下的局部插值。

最终求：

\[
\boxed{
g(t_{\rm dry})=0
}
\]

# 17. 防止事件误触发

长期模拟中不能因为单一离散节点短暂跌破 0.15 就终止。

事件附近需要检查：

- \(C_{\max}(t)\) 是否平滑下降；
- 是否存在非物理振荡；
- 是否产生 \(C<0\)；
- 最大值位置是否异常跳跃；
- 加密时间步后穿越时刻是否稳定。

建议将结束事件定义为：

\[
\boxed{
\text{第一次稳定的向下阈值穿越}
}
\]

# 19. 长时间积分稳定性检查

由于 Q3 远长于 Q2，必须增加长期稳定性监控。

至少检查：

1. 每一步非线性迭代是否收敛；
2. \(C>0\)；
3. \(D>0\)；
4. 是否出现局部非物理水分反弹；
5. 总体水分趋势是否合理；
6. 热量/水分数值守恒残差是否长期积累；
7. 后期自适应步长是否过大而影响事件检测；
8. Robin 边界通量方向是否始终合理。

# 23. 长期边界敏感性

建议定义：

\[
\delta_{\rm BC}
=
\frac{
\max(t_{\rm dry}^{(A)},t_{\rm dry}^{(B)},t_{\rm dry}^{(C)})
-
\min(t_{\rm dry}^{(A)},t_{\rm dry}^{(B)},t_{\rm dry}^{(C)})
}{
t_{\rm dry}^{(A)}
}.
\]

若 \(\delta_{\rm BC}\) 很小，则主方案对环境延拓具有较强稳健性。

若偏差明显，则需要把外推不确定性作为模型局限报告。

# 24. 建议的物理参数敏感性

优先关注：

\[
D(C,T),
\qquad
h_m,
\qquad
T_{\infty,\rm long},
\qquad
C_{\infty,\rm long}.
\]

其理由：

- \(D\)：决定内部水分迁移能力；
- \(h_m\)：控制外表面传质阻力；
- \(T_{\infty,\rm long}\)：通过 \(D(C,T)\) 影响内部扩散；
- \(C_{\infty,\rm long}\)：改变表面传质驱动力。

# 25. “后期越来越难干”的公式机制

这一节只给由附录 3 公式直接支持的趋势，不预设最终数值结果。

在平台温度约：

\[
T_\infty\approx50.00^\circ C
\]

附近，按：

\[
D(C,T)
=
2.4\times10^{-3}
e^{-0.45/C}
e^{-3850/T_K}
\]

计算：

\[
D(C=2.55)
\approx
1.347e-08\ \mathrm{m^2/s},
\]

而：

\[
D(C=0.15)
\approx
8.001e-10\ \mathrm{m^2/s}.
\]

两者比值约：

\[
\frac{D(2.55)}{D(0.15)}
\approx
16.8.
\]

所以在温度近似相同时：

\[
\boxed{
C\downarrow
\Rightarrow
D\downarrow
}
\]

并且下降幅度可能很显著。

简单径向扩散时间尺度：

\[
\tau_D\sim\frac{R^2}{D}
\]

对应约从：

\[
8.2\ \mathrm h
\]

增加到：

\[
138.9\ \mathrm h.
\]

**这些时间尺度不是最终烘干时间预测，只用于说明低含水率阶段扩散显著变慢的数量级机制。**

最终仍需用数值结果回答：

- 温度何时接近平台；
- \(D(r,t)\) 如何变化；
- 中心与表面梯度如何演化；
- 是否出现显著后期减速。

# 29. 问题 3 最容易被评委质疑的 5 个地方

## 质疑 1：4 h 后环境为什么可以取常数？

回答：

> 附件 1 仅覆盖 4 h，因此 Q3 必须外推。末 1 h 环境温度和环境水分的线性趋势已接近零、标准差较小，故把 3–4 h 识别为稳定平台，并使用平台均值恒定延拓；同时用末值和 2.5–4 h 均值做 \(t_{\rm dry}\) 敏感性验证。

## 质疑 2：为什么不直接只检查中心？

正式判据始终是：

\[
C_{\max}(t)<0.15.
\]

只有计算验证最大值始终在中心后，才可事后解释为中心控制。

## 质疑 3：为什么 Q3 仍然计算温度？

因为：

\[
D=D(C,T).
\]

不计算长期温度会改变问题 2 的物理模型。

## 质疑 4：为什么烘干时间不是 60 s 整数倍？

因为 60 s 只是 Excel 输出间隔，真实终止时间由连续事件：

\[
g(t)=0
\]

定位。

## 质疑 5：为什么不加入尺寸收缩？

因为收缩是问题 4 的独立新增机制。Q3 必须保持固定半径作为对照基准。

\boxed{

}

全空间指标：

\[
\boxed{
C_{\max}(t)
=
\max_{0\le r\le R}C(r,t)

终止时间：

\[
\boxed{
t_{\rm dry}
=
\inf

}

事件函数：

g(t)=C_{\max}(t)-0.15

通过第一次向下零点确定结束时刻。
