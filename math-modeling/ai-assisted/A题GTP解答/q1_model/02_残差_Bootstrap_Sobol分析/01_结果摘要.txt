第一问误差、Bootstrap与Sobol分析结果摘要

一、残差定义
本分析统一采用：残差 = 观测值 - 模型预测值。
RMSE越接近0越好；决定系数R²越接近1，表示拟合对数据总体变化的解释程度越高。

二、误差指标
1. 烘房温度边界处理：
   表1主模型直接使用附件1的分段线性插值，在原始60 s节点处残差为0。
   保留的辅助非线性拟合：RMSE = 0.144193 ℃，MAE = 0.123680 ℃，
   R² = 0.999202，最大绝对残差 = 0.328610 ℃。

2. 烘房水分边界拟合：
   RMSE = 0.000207676 kg/kg
   MAE  = 0.000170510 kg/kg
   R²   = 0.999346
   最大绝对残差 = 0.000459410 kg/kg

3. PINN相对CN（35个题目指定时空点）：
   温度RMSE = 0.009867 ℃，R² = 0.999980
   水分RMSE = 0.017449 kg/kg，R² = 0.996859

4. 守恒残差：
   热量守恒相对残差 = 1.074685×10^(-12)
   水分守恒相对残差 = 2.422109×10^(-14)
   注意：守恒残差很小不等于实际预测误差达到10^(-12)。

三、1000次移动块Bootstrap结果
温度边界曲线：
   稳态值 ySteady：49.988～50.050 ℃
   时间尺度 tau：1872.8～1895.1 s
   形状参数 beta：1.1386～1.1607

水分边界曲线：
   稳态值 ySteady：0.050250～0.050356 kg/kg
   时间尺度 tau：2706.2～2760.1 s
   形状参数 beta：1.2274～1.2720

水分ySteady区间下限碰到拟合约束下界，因此该区间属于受约束的单侧区间。
温度拟合已经取消“稳态值必须大于全部观测最大值”的错误约束。
高R²说明总体曲线吻合良好，但不代表残差完全随机；表1主结果不再使用该辅助拟合。

四、Sobol一阶效应与总效应
正式计算采用2048组基样本、6个参数，共16384次模型运行；
Sobol指数的95%区间由1000次Bootstrap得到。

主要结论：
1. 1800 s中心温度主要受体积热容rho*cp影响：
   S1 = 0.5343，ST = 0.5350，ST的95%区间为0.5050～0.5664。

2. 1800 s表面温度主要受热对流系数hT影响：
   S1 = 0.7515，ST = 0.7524，ST的95%区间为0.7151～0.7943。

3. 1800 s体积平均温度主要受hT影响，其次是rho*cp：
   hT：S1 = 0.5615，ST = 0.5623；
   rho*cp：S1 = 0.4143，ST = 0.4145。

4. 最大径向温差主要受导热系数k影响：
   S1 = 0.5826，ST = 0.5855，ST的95%区间为0.5527～0.6182。

5. 1800 s表面含水率由D0和hM共同主导：
   D0：S1 = 0.5149，ST = 0.5170；
   hM：S1 = 0.4724，ST = 0.4745。

6. 体积平均含水率和平均失水量主要受hM影响：
   hM：S1 = 0.7856，ST = 0.7992，ST的95%区间为0.7587～0.8418；
   D0：S1 = 0.1974，ST = 0.2106。

7. 一阶效应与总效应总体接近，说明在当前假设区间内交互作用较弱；
   平均水分输出中D0和hM存在小幅交互，不能只报告一阶效应。

五、可靠性检查
1. 1024组增至2048组时，所有Sobol指数的最大变化为0.002341，小于0.02。
2. Sobol总效应均位于0～1之间，未出现S1显著大于ST的情况。
3. 敏感性分析网格相对第一问细网格的最大温度差为0.000900 ℃，
   最大水分差为0.000484 kg/kg，低于预设误差标准。

六、必须写在论文中的限制
附件没有给出物性参数的概率分布或标准差。本Sobol分析使用的是人为设定的工程探索区间，
结果表示“在这些假设区间下哪些参数最重要”，不能直接解释成真实参数不确定度的概率结论。
