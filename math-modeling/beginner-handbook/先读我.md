# 国赛 A 题零基础公式与代码手册

先打开《国赛A题通用公式与代码_零基础详解.pdf》。共 73 页，含 164 组独立展示公式环境（一个环境可能包含多个等式）。

覆盖：数学记号与单位、通用数学工具、ODE、热传导显式/隐式/Crank–Nicolson 差分、基础定理、非线性优化、力学、光学、热学、流体、概率统计、代表性基础与前沿文献、逐行注释代码。

每个公式附近说明符号、单位、条件和含义；所有三个 Python 脚本的非空行都附中文解释。示例数据为教学构造，不是材料实测参数。

## 文件

- PDF：直接阅读和打印，含可点击目录及文献链接。
- 完整手册_单文件源代码.tex：完整 LaTeX，自带嵌入的代码段，不依赖 chapters/code 文件即可编译。
- main.tex、preamble.tex、physics.tex、closing.tex、chapters/：便于分章编辑的同一份 LaTeX 工程。
- code/ode_template.py：冷却 ODE、阈值事件定位、解析解验证。
- code/heat_1d.py：三种时间离散、带状求解器、解析解与网格收敛验证。
- code/optimize_template.py：SLSQP 约束优化、多初值核验、非线性最小二乘参数拟合。
- 公式与知识点索引.md：按主题定位。
- 验证记录.txt：本机实际运行结果和版本。

## 运行 Python

在本目录打开 PowerShell 或终端，安装 Python 3.11 以上，然后逐行执行：

```powershell
python -m pip install numpy scipy  # 安装数组计算与科学计算依赖
python code/ode_template.py  # 运行并验证ODE模板
python code/heat_1d.py  # 运行并验证三种热差分方法
python code/optimize_template.py  # 运行优化与拟合模板
```

若系统找不到 python，先安装 Python 并确保命令可用。程序不是在 Word 或 PDF 中执行。更换实际赛题数据与方程后，要重新检验假设和误差。

## 编译 LaTeX

本机已使用 TeX Live 2026 / XeLaTeX 编译。字体配置为 Windows 的宋体、黑体和 Consolas。

```powershell
xelatex -interaction=nonstopmode -halt-on-error main.tex  # 第一遍生成正文与目录数据
xelatex -interaction=nonstopmode -halt-on-error main.tex  # 第二遍更新目录页码
```

也可在编辑器中打开“完整手册_单文件源代码.tex”，选择 XeLaTeX 编译两遍。单文件版本与分章版本二选一编辑即可。

在 Overleaf 或非 Windows 环境：将文档类选项 fontset=windows 改成 fontset=fandol，并把 setmonofont 中的 Consolas 改成 Latin Modern Mono；编译器选 XeLaTeX。PDF 已生成，无须编译即可阅读。

## 范围

这是国赛工程物理建模常用核心方法的综合入门手册，不是全部学科和全部文献的穷尽清单，也不针对某一届赛题。前沿部分选取 PINN、SINDy、WSINDy、POD、GP、贝叶斯优化、DeepONet、FNO 等代表路线，并明确适用限制。文献与链接写在对应公式附近；网络核查日期 2026-09-10。
